# Source pack for Issue #19

Дата проверки: 2026-10-11.

Этот пакет нужен только для определения вариантов целевой аудитории. Он не является окончательной оценкой перечисленных проектов.

## Исходная мотивация автора проекта

Автор — backend-разработчик, который хочет освежить знания для прохождения System Design интервью. Основные проблемы:

- без плана легко слишком глубоко уйти в первую тему;
- при глубоком изучении отдельных тем можно не покрыть разнообразие вопросов;
- отсутствует понятная структура подготовки;
- полезные материалы разбросаны по книгам, видео, каналам и статьям;
- итоговый roadmap и база знаний должны быть открытыми.

Источник: исходный пользовательский пост, на основании которого создан репозиторий.

## Сравниваемые проекты

### System Design Primer

- URL: https://github.com/donnemartin/system-design-primer
- Заявленная цель: изучение проектирования масштабируемых систем и подготовка к System Design интервью.
- Аудитория явно не разделена по грейдам.
- Содержит фундаментальные темы, подход к интервью и примеры задач.
- Структура рассчитана одновременно на обучение и справочное использование.

### Senior Engineer Interview Prep

- URL: https://github.com/calmrocks/senior-engineer-roadmap
- Заявленная аудитория: middle-разработчики, готовящиеся к senior-интервью; senior-разработчики, готовящиеся к staff; инженеры, которым нужен структурированный путь.
- Разделяет уровни `mid`, `senior` и `staff`.
- Содержит roadmap, недельные планы, checklists и cheatsheets.
- System Design является частью более широкого процесса подготовки senior/staff.

### Grokking System Design

- URL: https://github.com/design-gurus/grokking-system-design
- Обучает повторно используемым building blocks вместо запоминания готовых ответов.
- Предлагает разные маршруты: быстрый недельный, двухнедельный, шестинедельный и refresher для senior/staff.
- Включает patterns, вопросы, deep dives, cheat sheets и company guides.
- Предполагает разные ограничения по времени и разный предшествующий опыт.

### shubhag/systemdesign

- URL: https://github.com/shubhag/systemdesign
- Заявленная цель: подготовка к System Design интервью.
- Предлагает последовательность: framework и estimation, затем core building blocks, затем специализированные компоненты.
- Делит материалы на обязательное ядро и темы, которые подключаются по необходимости.
- Не содержит явного отдельного трека для начинающих backend-разработчиков.

### System Design & Architecture Notes

- URL: https://github.com/sajidhamdard/system-design
- Заявленная аудитория: кандидаты на System Design интервью, разработчики production-систем и инженеры, переходящие к senior/staff.
- Путь начинается с fundamentals, затем переходит к базам данных, caching, distributed systems, networking, scaling и задачам.
- В репозитории обнаружены добавленные PDF книг; правовой статус таких файлов необходимо проверять отдельно.

### HLD and LLD Interview Handbook

- URL: https://github.com/param087/hld-lld-interview-handbook
- Объединяет high-level и low-level design.
- Roadmap включает 45-минутный framework, back-of-the-envelope estimation, networking, API design, load balancing и другие building blocks.
- Охват шире нашего предполагаемого backend HLD scope.

## Уже зафиксированное в нашем репозитории

- Основной язык — русский.
- Основной фокус — backend System Design интервью.
- Предварительная аудитория — backend-разработчики уровня junior+/middle и выше.
- Предполагаются стартовые знания HTTP, SQL, структур данных и серверной разработки.
- Проект должен отвечать: что изучать, насколько глубоко и как проверить готовность двигаться дальше.
